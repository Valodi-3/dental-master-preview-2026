# V6 — дизайн-направление по AGRR Beauty

## Задача

Полностью обновить локальный preview двух сайтов ДантистЪ по прямому запросу владельца. Референс — [agrrbeauty.com](https://agrrbeauty.com/): тёплая поверхность бумаги/песка вместо холодного белого, крупная editorial-типографика, асимметричная сцена «слова + большое фото», пронумерованные направления, тонкие правила и смена настроения между секциями. Повторно прочитанный первый экран и блок услуг дают наблюдаемую основу; стили и контент салона не копируются.

## Что меняется

- Одна общая visual system подключается ко всем 41 статическим маршрутам и chooser; root preview hub входит в тот же стиль.
- Внутренние страницы получают тёплый фон, насыщенные, но сдержанные лесные/земляные акценты, редакционные заголовки, фотографии и линейную, а не «коробочную» подачу.
- Главные сохраняют welcome-first: интерьер/пространство филиала, никаких подборов услуг или коммерческого CTA в hero. Схема контента: приветствие → клиника/галерея → необязательный интерактив каталога → листаемые профили врачей → контакты.
- Плавающая запись остаётся отдельной кнопкой снизу справа, с выбором подтверждённых каналов.
- Тонкий CSS motion/перспектива без генерации, тяжёлых библиотек, внешних картинок или шрифтов.
- Сохраняются реальные цены/идентификаторы, подтверждённые фотографии, 41 маршрут, поиски/фильтры, профильные документы и особая пометка филиала Прокшино в онлайн-ссылке Испанских кварталов.

## Запреты и границы

Не копировать HTML, изображения, заголовки, маркетинговые утверждения, услуги или фирменный знак AGRR. Не добавлять не подтверждённые медицинские обещания или данные врачей. Не менять `app.js`, tech-ветку, PR #1, main, GitHub Pages source, production-сайты или их данные. Публиковать результат только в существующую изолированную design-ветку/Open Draft PR #2; не объединять.
