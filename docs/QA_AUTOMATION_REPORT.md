## 3. Детализация обнаруженных дефектов верстки (для передачи Manus)

### Дефект №1: Горизонтальный скролл на 1024px (Прокшино)
- **Файл:** `prokshino.css` / `prokshino.html`
- **Координаты:** `scrollWidth = 1060px` при ширине окна `1024px` (+36px).
- **Селекторы переполнения:**
  1. `.header-actions` (ширина `299px`, не сжимается в медиа-брейкпоинте 1024px).
  2. `.hero-ambient-glow` выходит за правый край окна, так как у родительского контейнера `.hero-section` не задан `overflow: hidden`.
- **Решение для Manus:** Задать `.hero-section { overflow: hidden; }` и добавить `@media (max-width: 1100px) { .header-actions { width: auto; } }`.

### Дефект №2: Три битых фотографии врачей на Испанских кварталах (HTTP 404)
- **Файл:** `ispanskie.html`
- **Проблема:** Браузер фиксирует `naturalWidth === 0` для 3 изображений из-за 404 ошибки на домене `stomatolog-ispanskie-kvartaly.ru`:
  1. `.../portraits/portrait-02.webp`
  2. `.../portraits/anna-karapetyan-960.jpg`
  3. `.../portraits/portrait-01.webp`
- **Решение для Manus:** Заменить базовый хост на `https://dantist-prokshino.ru/wp-content/themes/your-clean-template-3/studio-staff/portraits/...`, где эти файлы отдают 200 OK.

### Дефект №3: Отсутствие триггера модального окна в шапке Прокшино
- **Файл:** `prokshino.html`
- **Проблема:** Кнопка записи в хедере Прокшино не имеет дата-атрибута `[data-booking-trigger]`, на который подписан `app.js`.
- **Решение для Manus:** Добавить атрибут `data-booking-trigger` к кнопке записи в шапке `prokshino.html`.

## 4. Инструкция по переносимому запуску сьюта

Тестовый сьют полностью автономен и не содержит локальных абсолютных путей:
```bash
# Переход в папку тестов и установка зависимостей
cd tests
npm install

# Установка браузерного движка (при необходимости)
npx playwright install chromium

# Запуск полного матричного тестирования
node run-qa-suite.cjs
```
Любая ошибка или несоответствие селекторов приводит к статусу `FAIL` и ненулевому коду возврата (exit code 1).
