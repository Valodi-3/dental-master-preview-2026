## 2. Структура устанавливаемых пакетов

В директории `integration/wordpress-staging/` подготовлены готовые к установке архивы:

### 2.1. Дочерняя тема: `your-clean-template-3-child.zip`
Устанавливается через *WordPress Admin -> Внешний вид -> Темы -> Добавить новую -> Загрузить тему*:
```
your-clean-template-3-child/
├── style.css                      # Заголовок дочерней темы (Template: your-clean-template-3)
├── functions.php                  # Безопасное подключение CPT, стилей и noindex заголовков
├── template-prokshino-vnext.php   # Изолированный шаблон страницы для филиала Прокшино
├── template-ispanskie-vnext.php   # Изолированный шаблон страницы для филиала Испанские кварталы
├── includes/
│   ├── cpt-services.php           # Регистрация CPT 'dental_service' и таксономии 'dental_category'
│   └── cpt-doctors.php            # Регистрация CPT 'dental_doctor' (стаж, специализации)
└── assets/
    ├── css/
    │   ├── prokshino.css          # Стили Прокшино
    │   └── ispanskie.css          # Стили Испанские кварталы
    └── js/
        └── app.js                 # Интерактивная логика каталога и модальных окон
```

### 2.2. Изолированный шлюз предпросмотра: `dental-vnext-staging.zip`
Устанавливается через *WordPress Admin -> Плагины -> Добавить новый -> Загрузить плагин*:
```
dental-vnext-staging/
├── dental-vnext-staging.php       # Проверка прав пользователя (current_user_can('read')),
```

## 3. CLI-импорт каталога (`import-services-cli.php`)

Для синхронизации каталога из 254 услуг без ручного ввода подготовлен скрипт для `WP-CLI`:
```bash
# 1. Запуск валидации каталога без записи в БД (Dry-Run):
wp eval-file import-services-cli.php --dry-run

# 2. Боевой импорт с пропуском уже существующих позиций:
wp eval-file import-services-cli.php --skip-existing

# 3. Импорт из альтернативного файла:
wp eval-file import-services-cli.php --file=/var/www/data/wp_services_import.json
```

### Защитные механизмы импортера:
- **Динамический поиск файла данных:** Проверяет аргумент `--file`, переменную окружения `DENTAL_SERVICES_IMPORT_FILE`, пути относительно корня репозитория и `wp-content`.
- **Строгая валидация JSON и схемы:** Проверяет наличие `post_title`, `_service_sku`, цен (`_price_prokshino` / `_service_price_rub`) и категорий.
- **Защита от дубликатов:** Поиск существующих постов по `meta_key = '_service_sku'` предотвращает дублирование услуг при повторных прогонах.
- **Обработка ошибок:** Выводит детализированный отчёт с количеством созданных, обновленных, пропущенных и сбойных записей.

## 4. Защита боевого домена (Production Safety)

1. **Отсутствие влияния на активную тему:** Пока в админке не переключена активная тема или не назначен кастомный шаблон страницы, действующий сайт клиники работает на 100% без изменений.
2. **Изоляция поисковых роботов:** Любой staging-шаблон или предпросмотр отдает HTTP-заголовок `X-Robots-Tag: noindex, nofollow, noarchive, nosnippet`, предотвращая попадание черновиков в индекс Яндекса и Google.
3. **Ролевой доступ:** Просмотр предпросмотра разрешен только авторизованным пользователям с правом чтения (`read`) в админке WordPress.
