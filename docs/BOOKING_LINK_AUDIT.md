## 2. Детальный разбор DentalPRO

1. **Филиал Прокшино (`dantist-prokshino.ru`):**
   * Страница `https://dantist-prokshino.ru/online-zapis/` возвращает HTTP-код `200`.
   * Содержит интеграцию виджета DentalPRO через JavaScript-бандл темы `your-clean-template-3/js/common.js`.
   * Пациент может выбрать филиал, специальность врача и свободный интервал приёма.

2. **Филиал Испанские кварталы (`stomatolog-ispanskie-kvartaly.ru`):**
   * Прямой адрес `https://stomatolog-ispanskie-kvartaly.ru/online-zapis/` возвращает HTTP-код `404`.
   * В REST API `wp-json/wp/v2/pages` Испанских кварталов страницы со слагом `online-zapis` нет.
   * На действующем боевом WordPress-сайте клиники кнопка «Записаться онлайн» ссылается непосредственно на Прокшино:  
     `href="https://dantist-prokshino.ru/online-zapis/"`.
   * *Причина:* согласно документации техподдержки DentalPRO, интеграционный токен выдавался на домен Прокшино как головной.

> **Рекомендация для интерфейса Manus:**  
> В обоих черновиках (`prokshino.html` и `ispanskie.html`) кнопка DentalPRO обязана открывать именно `https://dantist-prokshino.ru/online-zapis/` с атрибутами `target="_blank" rel="noopener"`. Никогда не использовать адрес `stomatolog-ispanskie-kvartaly.ru/online-zapis/`, так как он ведёт на страницу ошибки.

## 3. Различие между WhatsApp, Telegram и звонком

1. **WhatsApp Business (`wa.me/message/2WBFWCZJGHQDG1`):**
   * Идеален для мобильных пользователей (iOS / Android).
   * Сразу открывает предзаполненный чат с клиникой.
   * Администратор видит имя и номер телефона пациента.

2. **Telegram (`t.me/Stomatologiya1108`):**
   * На десктопе у пользователей без установленного клиента Telegram открывает лендинг-заглушку с предложением скачать приложение.
   * В интерфейсе необходимо маркировать кнопку как «Telegram-канал / чат», чтобы у пользователя не возникало ожидания автоматического онлайн-букинга.

3. **Телефонная ссылка (`tel:+79045199697`):**
   * Должна быть оформлена строго в формате E.164 (`tel:+79045199697` без пробелов и дефисов в значении `href`, при этом видимый текст может быть отформатирован для удобства чтения: `+7 (904) 519-96-97`).
