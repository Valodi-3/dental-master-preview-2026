## Дефекты и расхождения старого preview

- Страница Испанских кварталов указывала адрес «бульвар Веласкеса / ул. Сервантеса, 1»; актуальный официальный источник указывает ул. Магеллана, 5.
- Старые preview-страницы содержали не подтверждённые production-источниками заявления о рейтинге, конкретных марках оборудования, 25-кратной оптике, КЛКТ, некоторых методах и гарантиях. Эти утверждения не перенесены.
- В старых карточках врачей часть ФИО, специализаций и стажа не совпадала с официальными страницами. Использованы опубликованные написания и роли.
- Несколько промо-цен старого preview не совпадали с точными строками прайса. На главных страницах оставлены только приведённые выше проверенные позиции; полный список сохранён отдельно.
- В новой версии нет форм с фиктивным успехом. Запись Прокшино ведёт в опубликованный DentalPRO; Испанские кварталы — на набор номера клиники.
