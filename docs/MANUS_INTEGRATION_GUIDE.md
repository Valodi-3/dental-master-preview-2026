## 2. Обнаруженные дефекты верстки и точные координаты для Manus

По результатам прогона автоматизированного сьюта (`tests/run-qa-suite.cjs`, 27 проверок) выявлены **3 локальных дефекта**, требующих правки в файлах Manus:

### Дефект №1: Горизонтальный скролл на десктопе 1024px (Прокшино)
- **Файл:** `prokshino.html` / `prokshino.css`
- **Проблема:** При ширине вьюпорта `1024px` ширина страницы `scrollWidth = 1060px` (вылет на 36px вправо).
- **Причина (координаты):**
  1. Блок `.header-actions` имеет фиксированную ширину `299px`, из-за чего в `1024px` шапка не помещается в одну строку с логотипом и навигацией.
  2. Фоновое свечение `.hero-ambient-glow` выходит за пределы экрана, а на родительской секции `.hero-section` отсутствует свойство `overflow: hidden`.
- **Рекомендуемое решение:**
  ```css
  /* В prokshino.css */
  .hero-section {
    overflow: hidden; /* предотвращает горизонтальный вылет декоративных градиентов */
    position: relative;
  }

  @media (max-width: 1100px) {
    .header-actions {
      width: auto;
      gap: 8px;
    }
    .header-phone-text {
      display: none; /* скрывать длинный текстовый номер, оставляя кликабельную иконку трубки */
    }
  }
  ```

### Дефект №2: Две битые фотографии врачей (HTTP 404) на Испанских кварталах
- **Файл:** `ispanskie.html`
- **Проблема:** В браузере не отображаются две фотографии врачей (`naturalWidth === 0`), сервер отдает 404 Not Found:
  1. `https://stomatolog-ispanskie-kvartaly.ru/wp-content/themes/your-clean-template-3/studio-staff/portraits/anna-karapetyan-960.jpg`
  2. `https://stomatolog-ispanskie-kvartaly.ru/wp-content/themes/your-clean-template-3/studio-staff/portraits/portrait-01.webp`
- **Причина:** На домене Испанских кварталов в теме отсутствуют эти файлы, однако **оба файла физически существуют и отдают 200 OK** на основном домене `dantist-prokshino.ru`.
- **Рекомендуемое решение в `ispanskie.html`:**
  Заменить базовый URL для данных двух изображений:
  ```html
  <!-- БЫЛО (404 Not Found): -->
  <img src="https://stomatolog-ispanskie-kvartaly.ru/wp-content/themes/your-clean-template-3/studio-staff/portraits/anna-karapetyan-960.jpg" ...>
  <img src="https://stomatolog-ispanskie-kvartaly.ru/wp-content/themes/your-clean-template-3/studio-staff/portraits/portrait-01.webp" ...>

  <!-- СТАЛО (200 OK): -->
  <img src="https://dantist-prokshino.ru/wp-content/themes/your-clean-template-3/studio-staff/portraits/anna-karapetyan-960.jpg" ...>
  <img src="https://dantist-prokshino.ru/wp-content/themes/your-clean-template-3/studio-staff/portraits/portrait-01.webp" ...>
  ```

### Дефект №3: Отсутствие триггера модального окна в кнопке шапки Прокшино
- **Файл:** `prokshino.html`
- **Проблема:** В шапке кнопка «Записаться» не открывает модальное окно выбора каналов связи, в то время как на странице Испанских кварталов и в плавающем баре она работает корректно.
- **Причина:** В `app.js` навешен слушатель на атрибут `[data-booking-trigger]`. В кнопке шапки Прокшино данный дата-атрибут отсутствует.
- **Рекомендуемое решение:**
  Добавить атрибут `data-booking-trigger` на кнопку записи в хедере `prokshino.html`:
  ```html
  <button type="button" class="btn btn-primary" data-booking-trigger>Записаться</button>
  ```

## 3. Каталог услуг (254 позиции, 10 категорий)

С действующего сайта выгружен, распарсен и валидирован полный каталог цен:
- `data/services_master.json` — единый мастер-файл каталога;
- `data/services_prokshino.json` и `data/services_ispanskie.json` — привязка к конкретным клиникам;
- `data/categories_summary.json` — сводка по 10 категориям;
- `data/wp_services_import.json` — формат для прямого импорта в WordPress.

### 10 клинических категорий:
1. `consultations` — Консультации и первичный осмотр (9 услуг, 0 – 3 300 ₽)
2. `diagnostics` — Диагностика и снимки (4 услуги, 550 – 1 980 ₽)
3. `anesthesia` — Анестезия (5 услуг, 440 – 1 650 ₽)
4. `hygiene` — Профессиональная гигиена и отбеливание (11 услуг, 165 – 33 000 ₽)
5. `treatment` — Терапия и лечение кариеса (19 услуг, 165 – 11 000 ₽)
6. `endodontics` — Эндодонтия и лечение каналов (16 услуг, 1 100 – 19 800 ₽)
7. `surgery` — Хирургическая стоматология (33 услуги, 660 – 19 800 ₽)
8. `implantation` — Имплантация зубов (25 услуг, 660 – 82 500 ₽)
9. `prosthetics` — Ортопедия и протезирование (65 услуг, 1 100 – 396 000 ₽)
10. `orthodontics` — Ортодонтия и исправление прикуса (67 услуг, 660 – 350 000 ₽)

### Важное предупреждение по дубликатам названий:
В официальном прайс-листе присутствуют 4 услуги с абсолютно идентичными названиями в разных разделах (например, полиэфирный слепок в ортопедии стоит 1 980 ₽, а в ортодонтии — 3 000 ₽).  
**Правило:** В скриптах поиска и фильтрации используйте составной идентификатор `id` (например, `svc_prosthetics_1` и `svc_orthodontics_12`), а не поиск только по названию.

## 5. Как запускать автоматические тесты верстки

Тестовый сьют написан на Playwright и проверяет 9 разрешений, переполнение, битые картинки, модалки и ссылки:

```bash
# Запуск сьюта из корня репозитория
node tests/run-qa-suite.cjs
```

Сьют формирует машиночитаемый отчёт `tests/qa-report.json` и выводит консольную сводку со статусом каждого теста.
