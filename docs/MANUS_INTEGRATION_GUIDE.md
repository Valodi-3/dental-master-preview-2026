## 2. Обнаруженные дефекты верстки и точные координаты для Manus

Автоматизированный матричный сьют Playwright (`tests/run-qa-suite.cjs`, 30 проверок) зафиксировал **3 дефекта**, требующих исправления в дизайне:

### Дефект №1: Горизонтальный скролл на 1024px (Прокшино)
- **Файлы:** `prokshino.css` / `prokshino.html`
- **Координаты ошибки:** `scrollWidth = 1060px` при ширине вьюпорта `1024px` (+36px переполнение).
- **Причина:**
  1. Блок `.header-actions` имеет фиксированную ширину `299px` и не помещается в одну строку в медиа-брейкпоинте 1024px.
  2. Фоновое свечение `.hero-ambient-glow` выходит за правый край, а на секции `.hero-section` отсутствует свойство `overflow: hidden`.
- **Решение для Manus в `prokshino.css`:**
  ```css
  .hero-section {
    position: relative;
    overflow: hidden; /* предотвращает горизонтальный вылет радиальных градиентов */
  }

  @media (max-width: 1100px) {
    .header-actions {
      width: auto;
      gap: 8px;
    }
    .header-phone-text {
      display: none; /* скрывать длинный текст номера, оставляя иконку вызова */
    }
  }
  ```

### Дефект №3: Отсутствие триггера модального окна в шапке Прокшино
- **Файл:** `prokshino.html`
- **Проблема:** Кнопка записи в хедере не имеет дата-атрибута `[data-booking-trigger]`, поэтому клик по ней не открывает модальное окно.
- **Решение для Manus в `prokshino.html`:**
  Добавить атрибут `data-booking-trigger` на кнопку записи в шапке:
  ```html
  <button type="button" class="btn btn-primary" data-booking-trigger>Записаться</button>
  ```

## 5. Запуск переносимого QA-тест-сьюта

Скрипт проверки не содержит абсолютных путей машины и готов к запуску на любом компьютере:
```bash
# 1. Перейти в каталог тестов и установить зависимости
cd tests
npm install

# 2. Установить Chromium (при первом запуске)
npx playwright install chromium

# 3. Запустить матричное тестирование (9 разрешений + функционал)
node run-qa-suite.cjs
```
Любой сбой assertion, ненайденный селектор или вылет за пределы экрана дает статус `FAIL` и завершает процесс с кодом ошибки.
